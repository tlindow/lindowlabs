# Extras: Fastify payments API

Optional follow-up after the OpenAPI track. Build a small **Fastify + TypeScript**
REST API for the payments domain in [SPEC.md](./SPEC.md).

## Start here

1. Read [SPEC.md](./SPEC.md).
2. `npm install`
3. `npm test` (expect failures until you implement handlers).
4. Edit `src/payments.ts`. Handler bodies are stubs on purpose.
5. Re-run `npm test` until green.

Optional: `npm run dev` starts the server on port `3030` for manual curls.
